Usuarios del panel

Creá una cuenta para cada persona que trabaje con vos, eligiendo qué puede hacer:
Vendedor: puede agregar y editar información, pero nunca borrar nada.
Secretaria: acceso operativo completo (agregar, editar y borrar).
Contador: solo puede consultar información (Cobranzas, Liquidaciones, Auditoría), no puede crear, editar ni borrar.
Administrador: acceso total, incluyendo Apariencia del sitio y gestión de usuarios.

Modelo de contrato de alquiler

Este es el texto que se usa para generar automáticamente el contrato de cada inquilino (botón "Generar contrato"). Podés agregar, borrar o editar cualquier cláusula. Usá estos códigos donde necesites que se complete un dato solo: {{PROPIETARIO_NOMBRE}} {{PROPIETARIO_DNI}} {{PROPIETARIO_DOMICILIO}} {{INQUILINO_NOMBRE}} {{INQUILINO_DNI}} {{INQUILINO_EMAIL}} {{PROPIEDAD_DIRECCION}} {{PROPIEDAD_CIUDAD}} {{PROPIEDAD_COMPOSICION}} {{FECHA_INICIO}} {{FECHA_FIN}} {{DURACION_MESES}} {{MONTO_TOTAL}} {{DETALLE_ALQUILER}} {{FIADORES_DETALLE}} {{INVENTARIO_DETALLE}} {{FECHA_FIRMA}} {{FIADORES_FIRMAS}}

Modelo de detalle de pago

El logo (imagen) y el título en negrita se editan en "Apariencia del sitio". Acá abajo podés armar libremente el resto: las líneas de arriba a la izquierda (dirección, teléfono, mail) y las notas del final (aviso sobre pagos, dónde mandar comprobantes). Usá estos códigos donde quieras que se completen solos: {{ADDRESS}} {{PHONE}} {{EMAIL}} (toman los datos de "Apariencia del sitio").
